# From a profile request to a reviewed change

Project-led composition demo, not a candidate résumé or a claim of ownership.

**[GH Aura](https://github.com/ibbuilds/gh-aura)** brings public project evidence, profile composition and optional private workflow exercises into one local CLI and agent interface.

- **Try:** create shared intent, generate a native draft or ask a chosen AI for an original composition, then inspect the change plan.
- **Inspect:** [project selection](../src/profile-projects.mjs), [shared context](../src/profile-context.mjs) and [installed-package checks](../scripts/package-smoke.mjs).
- **Know the limit:** a merged exercise is not an awarded achievement; readable output is not proof of hiring success.

A real user's version should add their confirmed contribution and an outcome they can substantiate. This example deliberately supplies neither.
