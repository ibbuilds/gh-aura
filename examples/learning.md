# A small project you can inspect

Composition demo for an owner beginning to show public work. This describes a public project; it makes no claim about a fictional person's authorship or experience.

[GH Aura](https://github.com/ibbuilds/gh-aura) is a local tool for planning GitHub profile changes with an owner-controlled review step.

Start with [the implementation](../src/profile-plan.mjs), then [the regression cases](../tests/profile-plan.test.mjs). A short explanation of one change the owner actually made is stronger than an unsupported list of skills.
