# Changelog

## 1.16.0 — 2026-11-12

- Added four **composable AI art directions** (barebones, minimal, technical, expressive) to the existing evidence-grounded `brief --prompt` workflow. No rigid templates or required AI API.
- Added optional **two-account, read-only private workspace preflight** using two separate local tokens. It verifies distinct identities and the same marked repo; it does not create fake collaboration or promise awards.
- Maintained one private workspace, explicit reviewed writes and the latest-only GitHub Release policy.
- Added regression tests for direction overrides, token separation, private repo checks and CLI boundaries.
