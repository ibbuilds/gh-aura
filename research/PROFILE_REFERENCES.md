# GitHub profile design references

These are **references for GH Aura's professional presentation research**, not reusable templates or people to imitate.

- **Eight** original profile references supplied by the user; **four** additional research candidates, all individually linked and reviewed against the current public `USERNAME/USERNAME` README on 2026-11-12.
- No reference has final user approval yet. Each entry records the **design direction**, patterns to learn from, elements *not* to copy and its provenance.
- **Core** means a strong compositional learning candidate, not an endorsement of every element. **Selective** means borrow only a particular pattern. **Edge case** shows an extreme style and must not become an automatic default.
- Extra profiles are research candidates, **not** verified members of the requested monthly Developers ranking. GitHub's daily Developers page was publicly accessible, but the monthly filtered page could not be verified. Monthly *repository* trending is a different ranking.
- No screenshots, photos, prose or graphics of third parties are stored. Original assets require permission. Popularity, stars and followers are not criteria for professional quality.
- Neither GitHub Pages nor a web gallery is needed. This research dataset is **not** currently shipped as an approved automatic design baseline. A separate approval/policy change must be made before it can influence prompts or MCP selection.
