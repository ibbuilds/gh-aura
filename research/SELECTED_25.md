# GH Aura — 25 selected composition references

**Scope:** 25 editorial examples chosen from [100 distinct public profile READMEs](PROFILE_REFERENCES.md) checked on 2026-11-12. The original eight user-provided examples remain in the 100-entry research bank. This is a **curated pattern shortlist**, not a ranking of technical ability, hiring outcomes or verified professional identity.

The selection prioritizes work evidence, legible structure, distinct purposes and restrained dependence on third-party assets. Read-only GitHub links are references: **do not copy biography text, artwork, GIFs, photos, badges or personal claims**. Full rendered desktop/mobile and light/dark acceptance remains pending.

## Non-selected cases

The other 75 entries **remain in the complete research bank**, with their distinct IDs, origin and evidence. In particular, the user-provided `yetone` and `poteto` are still retained as visual edge cases, but not default professional recommendations because their README content is largely an image or animation. A highly famous developer's nearly empty README is not an appropriate default for a newer developer.

## Acceptance and distribution

- Barebones **2**, minimal **6**, technical **8**, expressive **9** (classification of the selected compositional pattern, not a restrictive user-facing template).
- `gh-aura sources profiles --json` lists the 25 offline; `sources profile ID --json` inspects one; `sources patterns --query ... --direction ...` recommends at most two.
- Agent integrations access the same offline source; no model vendor is required, and no automatic GitHub writes or external media downloads are introduced.
- Review desktop/mobile, dark/light rendering, third-party-image availability and readability before treating the shortlist as fully field-validated.

No GitHub Pages site or hosted service is required. No new release should be published before CI and external acceptance gates.
