# v1 scope

**Purpose:** make real GitHub work easy to understand, entirely through commands the user chooses to run.

## Delivered

- Public-profile audit with evidence, unknown states and optional project README inspection.
- Configurable `minimal`, `regular` and `flashy` drafts, exact project selections and per-section switches.
- Explainable showcase recommendations; pin selection stays with the user.
- Achievement catalog with sources, exclusions, paid preferences, self-reported progress and selected public evidence.
- Annual contribution reports, visibility checklists and evidence-linked repository milestones.
- Provider-neutral JSON for optional external copywriting.
- Exact-draft preview and revision-bound README publishing initiated by a separate command.
- Cross-platform tests, installed-package verification, read-only live integration and versioned distribution artifacts.

## Explicit limits

GitHub grants awards. GH Aura cannot guarantee every achievement, independently verify all earned badges or grant historical awards. Program participation and other people's decisions remain external. Metadata/README signals are not proof of code quality or employment history.

The history module analyzes authentic records. Attribution and privacy settings are explained, not changed. It does not manufacture commits or career progression. The repository timeline is bounded by the scanned public inventory.

The only remote mutation is the profile repository README. Bio/photo changes, automatic pinning, bulk repository editing, PR-based publishing, scheduled audits and UI are outside v1. They are not unfinished steps required to use this release; future changes need their own justification and review.

## Acceptance

A fresh install must support `init → audit → profile → preview → apply`, with no write before an explicit reviewed apply. All six platform/runtime test combinations, installed-package tests and live read-only integration must pass before a release is published.
