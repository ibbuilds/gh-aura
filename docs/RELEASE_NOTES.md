# GH Aura v1.18.0

**More freedom for AI-created, professional GitHub READMEs.**

- Expanded source library to **30 curated resources**, with Spanish/English intent search, licensing, maintenance and GitHub compatibility notes.
- Added **25 independent layout techniques** for plain, technical, code-inspired, artistic and optional dynamic profiles.
- Added an opt-in, bounded local custom-source catalog; no remote assets auto-fetched.
- Added editable biography controls: voice, perspective, focus, length, user claims and supporting references.
- Added user media references, freeform visual briefs, contextual resource suggestions and provenance-aware writing prompts.
- New `sources design`, `agent bio` and MCP design/biography tools. No fixed README templates, AI subscription or remote agent writes.
- Added regressions for source security, bilingual requests, original prose controls, package installation and MCP resources.

Real agent-client and private GitHub tests remain external acceptance gates.
