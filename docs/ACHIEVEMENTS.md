# GitHub Achievements

Source-reviewed catalog: **7 active achievements** plus historical, experimental, internal and program/profile badges. GitHub controls actual awards and may change private-event rules.

| Active achievement | Reported criterion | One-account private workspace? |
| --- | --- | --- |
| Pull Shark | Merged PRs; reported thresholds **2 / 16 / 128 / 1,024** | Attemptable, not guaranteed |
| YOLO | Merge your own PR without a review | Attemptable, not guaranteed |
| Quickdraw | Close issue/PR within **5 min** | Attemptable, not guaranteed |
| Pair Extraordinaire | Real coauthored merged work | Needs another consenting author |
| Galaxy Brain | Accepted Discussion answers | Needs an authorized question author |
| Starstruck | Public repo stars | Needs independent people |
| Public Sponsor | GitHub Sponsors relationship | Requires payment |

Arctic Code Vault and Mars 2020 were historical events. Heart On Your Sleeve and Open Sourcerer have no dependable active award route. Internal GitHub and program badges are not ordinary repo achievements.

`badges auto` attempts only the first three events using one owned private workspace. `badges auto accounts` can additionally verify two authorized accounts have read access to that same repo, but does not manufacture coauthor credit or accepted answers. **Observed GitHub API events are not proof that the profile awarded a badge.** Check your GitHub profile after processing, and enable private achievements visibility yourself.

The [whole-profile workflow](IMPROVE.md) separately supports exact two-account coauthor/Q&A exercises and tier-gated campaigns under one reviewed plan. It requires existing account access, the necessary write scopes and reviewed content; setup remains an owner action. The catalog labels this as conditional automation. Private award eligibility is unverified until a live pilot observes the actual award.
