# Usability study (not conducted)

GH Aura has not been validated by independent users or hiring managers. The 200-account structural study does not establish hiring outcomes.

## Minimal protocol

1. Recruit at least five consenting developers across experience levels; use three actual agent clients. Do not collect tokens or private code.
2. Install the candidate identified by commit and tarball checksum; v1.18.0 does not contain unreleased changes. Test clean setup, activation, whole-profile inspection, role-specific project selection, README/bio drafting, saved refinements and the owner-controlled review step. Real private-account pilots belong to the owner under issue #48.
3. Check links/assets, accessible text alternatives, light/dark and mobile legibility, recovery and pending pins/PRs/awards. Record completion, time, errors, client/CLI versions and confusion between synthetic exercises and actual work.
4. Publish dated anonymized findings and revalidated fixes. Include hiring reviewers before making recruiter-specific claims; do not infer employment outcomes.

Participation must be optional and confidential. No sessions have been completed in this release.
