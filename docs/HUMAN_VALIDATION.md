# Usability study (not conducted)

GH Aura has not been validated by independent users or hiring managers. The 200-account structural study does not establish hiring outcomes.

## Minimal protocol

1. Recruit at least five consenting participants with different GitHub experience levels. Do not collect tokens or private repositories.
2. Ask each person to install the latest release and attempt: inspect real activity, understand badge eligibility, draft a README, and recommend pins.
3. Record completion, time, errors, confusion between synthetic and authentic contributions, and exact CLI version.
4. Publish only aggregate anonymized findings, sample size, date and limitations. Never claim improved employment outcomes without separate evidence.

Participation must be optional and confidential. No sessions have been completed in this release.
